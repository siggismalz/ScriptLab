# Synthetische PDF-Belege geordnet ablegen

Die drei mitgelieferten PDFs enthalten keine echten Geschäftsdaten. Zwei besitzen eine Textschicht mit jeweils einer eindeutigen Belegnummer und einem Datum. Sie werden bei bewusstem Ausführen als `2026-10/SYN-1001.pdf` und `2026-10/SYN-1002.pdf` in den gewählten Ablageordner kopiert. Die dritte Datei ist ein gerastertes Testbild ohne PDF-Textschicht. Dafür wird ein verständlicher Scan-/OCR-Hinweis ausgegeben; sie wird nicht irreführend anhand eines Dateinamens eingeordnet.

Alle drei Originaldateien bleiben unverändert im Eingang. Eine vorhandene Ablagedatei ist ein Konflikt und wird mit `FEHLER` erhalten. Das Beispiel enthält keine OCR und startet kein Office- oder Cloudprogramm. `parameter.json` enthält ausschließlich relative Testpfade. Öffnen, Vorschau und Prüflauf legen keine fachlichen Belegkopien an.
